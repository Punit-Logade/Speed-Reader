# RSVP Speed Reader ⚡

An advanced productivity tool that uses Rapid Serial Visual Presentation (RSVP) to help you read faster by eliminating eye movement.

## 🚀 Features
- **Optimal Recognition Point (ORP):** Highlights the center letter in red so your eyes stay fixed in one spot.
- **Adjustable Speed:** Start at 300 WPM and scale up to 1000+ WPM.
- **File Support:** Read from local .txt or word files, or manual text input.
- **Clean Architecture:** Separated logic (Engine) and presentation (UI) for easy maintenance.
